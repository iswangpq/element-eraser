免 Mac、免付费，在 Safari 点一下书签即可隐藏页面广告

方法一：直接收藏下面的链接（最快）

长按下面的蓝色按钮 → 在弹出菜单选「添加到收藏夹 / 添加到书签」。

⚡消除元素 ✓ 已复制，去 Safari 粘贴

若长按没出现「收藏」选项，用下面的方法二。

方法二：先存书签，再编辑地址（最稳）

1. 任意页面点 Safari 底部分享图标 →「添加书签」→ 存到「个人收藏」。
2. 打开书签列表 → 长按刚存的 →「编辑」→ 把地址整段换成下面框里的代码 → 完成。

✓ 已复制

怎么用

  1. 在 Safari 打开有广告的页面。
  2. 点一下「⚡消除元素」书签 —— 页面已存规则立刻全部隐藏，左上角提示「已套用 N 条」。
  3. 手指点哪个广告，哪个消失并记住；点错按「选父级」换上层；右上角「✕退出」结束。
  4. 下次再开这个站，只点一下书签，之前的广告就全没了。
⚠️ iOS Safari 不允许脚本自动运行：刷新页面后不会自动隐藏，每次打开页面需点一下书签（点完即套用已存规则）。这是系统限制，无法绕过。
