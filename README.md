# 网页元素消除器 Element Eraser

一个免费、纯本地的浏览器扩展：**点一下网页里的任意元素，把它永久隐藏**，刷新、换视频、SPA 跳转后依然生效。

不是通用广告拦截器，而是「精准清除器」——专治那些广告拦截器漏掉的、你就是不想看见的东西：B 站视频页的推广卡片、信息流里的软广、评论区上方的横幅、各种推荐位和弹窗。

- 完全免费、开源（MIT）
- 规则只存本机浏览器，**不联网、不上传、无账号**
- 精准优先：隐藏广告不会连评论区一起带走
- 纯前端实现，无后端、无依赖

---

## 安装

支持 **Chrome / Edge（Manifest V3）**。

1. 下载并**解压** `element-eraser.zip`，得到 `element-eraser` 文件夹。
2. 地址栏输入 `edge://extensions`（Chrome 用 `chrome://extensions`）。
3. 打开「开发人员模式 / 开发者模式」。
4. 点「加载解压缩的扩展」，选中**文件夹**（不是 zip）。
5. 工具栏出现蓝色禁止图标即安装成功。

> 改了代码后：在扩展页点 **重新加载 ↻**，再 **F5 刷新网页**，新脚本才会注入。
> 想在本地测试页 `ad-test.html` 上试：在扩展详情里打开「允许访问文件 URL」。

## 快速上手

1. 点工具栏图标 → **开始选择要隐藏的元素**（或按快捷键 `Ctrl+Shift+Y`）。
2. 鼠标移到目标上，会出现**蓝色边框缓缓亮起**，旁边的信息卡实时显示：
   - 目标 tag / class
   - 祖先链
   - 本页会命中几个元素
   - 面积占比与文本量（过大时会警告）
3. 点一下，弹出确认条：
   - **隐藏此元素** → 播放向上折叠动画，规则永久保存
   - **选父级** / `Alt+滚轮` → 选中外层容器（广告图和外层 div 同大时很有用）
   - **取消**
4. 之后刷新、换视频、SPA 跳转，规则自动重新应用。

**撤销**：隐藏后 10 秒内或点选模式中按 `Ctrl+Z`，也可以在弹窗点「撤销上一条」。
**退出**：`ESC`。

## 弹窗功能一览

| 区域 | 能做什么 |
|---|---|
| 开始选择 | 进入/退出点选模式（`Ctrl+Shift+Y`） |
| 撤销上一条 | 撤销最近隐藏的一条规则 |
| 导出规则 / 导入规则 | 备份/恢复全部规则为 JSON（按站点合并、自动去重） |
| 隐藏方式 | `移除占位`（display:none，默认）/ `保留占位`（visibility:hidden） |
| 暂停本站 | 临时关闭本站所有自动隐藏；页面顶部会有橙色横幅提示，点横幅即可恢复 |
| 显示被藏元素 | 预览模式：被藏的元素以橙色虚线描边显示，核对「到底藏了什么」；此时点选隐藏会自动退出预览并真正隐藏 |
| 按文本隐藏 | 输入关键词（如 `广告`、`Sponsored`、`推广`），自动隐藏含该文本的元素 |
| 导入 uBlock 风格规则 | 粘贴过滤规则文本，见下方语法 |
| 手动规则列表 | 每条可「定位」（页面闪烁高亮）、「重选」（失效时重新指定目标）、「删除」 |
| 自动规则列表 | 文本规则与导入规则的分组管理 |

## 规则是怎么做到「精准」的

普通点选隐藏工具最大的坑是：你点了广告图片，它存的 class 恰好和评论区头像共用，结果评论区一起没了。本扩展用三层机制解决：

1. **目标提升**：点到 `<img>` / `<span>` / 文字时，自动向上找到真正的广告容器（`<a>`、带 `role`、带广告语义 class、或尺寸相近的包裹层）再存规则。
2. **祖先作用域指纹**：规则同时记录目标的祖先链（如 `div.right-container > div.video-pod-above-modules`）；命中时祖先链不符就跳过——同 class 不同区域不会互相误伤。
3. **体量守卫**：目标占页面 >30%、正文 >800 字、子元素 >80 个时，确认条红色警告，需二次确认才隐藏。

另外还有**精准优先、降级兜底**：本页若完全无法按作用域精准命中（比如从 B 站首页换到视频页），会降级按 class 兜底，并在弹窗打上红色「宽松」标记——既保证跨页面可用，又提醒你可能需要点「重选」收紧。

## 规则语法（uBlock 风格）

在弹窗「导入 uBlock 风格规则」里粘贴，每行一条：

```
! 注释行
example.com##.ad-slot                    只在该域名及其子域生效
##.sponsor-box                           所有网站生效
@@example.com##.keep-me                  放行例外：命中该选择器的元素不隐藏
##div:has-text(推广)                     含指定文本的元素
##.ad-slot:upward(1)                     命中后向上取 1 级父元素
##div:matches-attr(aria-label=广告)
```

支持的操作符：`:has-text()`、`:upward(n)`、`:matches-attr()`。
网络过滤规则（`||ads.example.com^`）与脚本规则（`##+js(...)`）会自动忽略，导入后提示忽略条数。

## 特效与参数修改

所有动画参数集中在 `content.js` 顶部的 `EFFECTS` 对象：

```js
var EFFECTS = {
  pick: {              // 点选高亮蓝框
    rgb: '33,150,243', // 颜色 RGB
    alpha: .9,         // 边框最终透明度
    bgAlpha: .16,      // 填充最终透明度
    width: 2,          // 边框粗细 px
    radius: 3,         // 圆角 px
    fadeIn: 600        // 缓动亮起时长 ms
  },
  hide: {              // 隐藏动画
    style: 'collapse', // collapse | scale | blur | scan | iris
    duration: 350,     // ms
    easing: 'ease'
  }
};
```

| 想改 | 改哪里 |
|---|---|
| 隐藏动画风格 | `hide.style`：`collapse` 向上折叠（默认、不留空隙）/ `scale` 缩放 / `blur` 模糊消散 / `scan` 扫描擦除 / `iris` 圆形闭合 |
| 动画时长 / 缓动 | `hide.duration` / `hide.easing` |
| 蓝框颜色 / 淡入时长 / 粗细 / 圆角 | `pick.rgb` / `pick.fadeIn` / `pick.width` / `pick.radius` |

改完保存 → 重载扩展 + F5 页面生效。

## 数据存哪里

- 浏览器 `chrome.storage.local`
  - `eraser_rules_v1`：手动点选规则，按域名分组
  - `eraser_cosmetic_v1`：文本规则与导入的 cosmetic 规则
  - `eraser_settings_v1`：隐藏方式、暂停状态、预览状态
- 物理位置：浏览器用户数据目录下的 `Local Extension Settings\<扩展ID>\`
- **全部本地，不联网、不上传、不收集任何数据**。清除浏览数据或换电脑会丢失，请用「导出规则」备份。

## 已知限制

- 仅支持 **open** 模式的 Shadow DOM；closed shadow root 无法穿透。
- 不支持 `chrome://` 等浏览器内置页面。
- 部分站点用内联 `!important` 样式或频繁重建 DOM，可能需要点「重选」重新指定目标。
- 与广告拦截器职责不同：本扩展不拦截网络请求，只隐藏已经渲染出来的元素。建议配合 uBlock Origin 使用。
